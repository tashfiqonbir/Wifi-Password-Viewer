### ⚠️ Disclaimer
This tool is made **for educational purposes only**. 
It can only show passwords of WiFi networks that are **already connected/saved on your own PC**.
I am not responsible for any misuse of this code.

---

### ✨ Features
- **List All Saved WiFi**: Shows all WiFi profiles saved on your system
- **Extract Passwords**: Displays password in clear text for each network
- **Interactive CLI**: Choose WiFi by number to view password
- **Zero Dependencies**: Only uses built-in `subprocess` module
- **Lightweight & Fast**: Less than 20 lines of code
